📌 Overview
This repository contains my personal solutions to computational biology challenges from Rosalind.info.
The problems focus on genomics, RNA transcription, protein translation, combinatorics, probability, and other fundamental bioinformatics algorithms.

The goals of this project are to:

  Strengthen algorithmic problem-solving and computational thinking in a biological context.

  Practice clean, reproducible Python coding with proper documentation.

  Demonstrate applied knowledge of DNA/RNA sequence analysis and protein bioinformatics.

🧪 Skills Demonstrated
  Programming: Python 3, Jupyter Notebooks

  Bioinformatics Concepts: Sequence alignment, k-mers, GC content analysis, reverse complement, codon translation, probability in Mendelian inheritance, dynamic programming for alignment.

  Algorithmic Tools: Hash maps, recursion, combinatorics, graph traversal, dynamic programming.

Best Practices:

  Modular code design

  Docstrings and inline comments

  Version control with Git
